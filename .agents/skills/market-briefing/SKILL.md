# Market Briefing (KECOBUGS)

주제 선정이 자유로운 위클리 브리핑 — "이번 주 시장에서 있었던 흥미로운 이슈 +
투자/금융에 미치는 영향 + 우리가 취해야 할 태도"를 다룬다. 단순 자료 요약이나
일반론이 아니라 **최신 이슈 + 본인 견해**가 핵심이다 (노션 페이지 작성 규칙).

## 워크플로 개요

| 단계 | 실행 | 산출물 |
|---|---|---|
| 1. 원문 수집 | 사용자가 텔레그램/유튜브/뉴스레터 원문 붙여넣기 + 에이전트 웹 검색 | 이슈 후보 목록 |
| 2. 이슈 선정 | 사용자가 후보 중 택 1 (또는 직접 제시) | 확정 이슈 |
| 3. 초안 작성 (에이전트) | 시황 정리 + 초안 인사이트 제안 | 초안 원고 |
| 4. 사용자 수정 | 인사이트 문단을 사용자가 다듬음 | 최종 원고 |
| 5. 게시 안내 | 블로그 원고 + 노션 제출 텍스트 정리 | `archive/YYYY-Wxx.md` |

## 1단계 — 원문 수집

먼저 `scripts/.state/sections/*.json` 에 온디맨드 브리핑(`/brief`)이
남긴 섹션이 있는지 확인한다. 있으면 이미 중복 제거·검증까지 끝난 재료이므로
그대로 활용한다. 없으면 `daily/*.md` 의 원문 다이제스트를 읽는다.
어느 쪽이든 **최종본이 아니라 원자재**이므로 그대로 인용하지 말고 사실관계만
참고한다.

화이트리스트에 없는 채널(특정 섹터 예시)이나 유튜브·뉴스레터 원문은 사용자에게
붙여넣어 달라고 요청한다. **텔레그램 채널 내용을 직접 접근하거나 추측해서 지어내지
않는다** — `daily/` 파일에 있거나 사용자가 붙여넣은 내용만 사실로 취급한다.

동시에 웹으로 접근 가능한 아래 소스는 에이전트가 직접 검색·열람해 보완한다
(`README.md`의 참고자료 출처 목록):

- 메르의 블로그(네이버 블로그), 한국경제, 매일경제, 이투데이, 뉴스핌
- KDI 경제교육·정보센터, KCIF 국제금융센터, 한국금융연구원, 자본시장연구원(KCMI)
- thebell, 딜사이트

두 출처(사용자 붙여넣기 + 웹 검색)를 합쳐 이번 주 이슈 후보 2~4개를 한 줄 요약과
함께 제시한다.

## 2단계 — 이슈 선정

사용자가 후보 중 하나를 고르거나 직접 다른 이슈를 지정하면 확정한다. 여러 개를
합쳐서 써도 되지만, 노션 규칙상 "단순 요약"이 되지 않도록 하나의 중심 이슈로
좁히기를 권장한다.

## 3단계 — 초안 작성 (에이전트)

`templates/briefing_template.md` 형식에 맞춰 아래 두 부분을 쓴다.

- **시황 정리**: 사실 관계만. 숫자·날짜·출처를 명시한다. 근거 없는 수치를
  지어내지 않는다.
- **초안 인사이트**: "투자와 금융에 미치는 영향" + "취해야 할 태도"에 대한 관점을
  제안한다. 이 부분은 **반드시 초안임을 명시**하고, 사용자가 그대로 쓰지 말고
  검토·수정하도록 안내한다 (과제 취지가 본인 견해이기 때문).

## 4단계 — 사용자 수정

사용자가 인사이트 문단을 고치거나 다시 써달라고 하면 반영한다. 이 단계가 끝나야
"최종 원고"로 취급한다.

## 5단계 — 게시 안내

최종 원고가 정해지면:

1. **블로그 원고**: 제목 + 본문을 그대로 복사해 네이버 블로그에 붙여넣을 수 있는
   형태로 정리해 채팅에 출력한다. 게시는 사용자가 직접 한다 (에이전트가 네이버
   블로그에 자동으로 글을 올리지 않는다).
2. 사용자가 게시 후 블로그 URL을 알려주면, 노션 "Market Briefing" 페이지에
   붙여넣을 제출용 텍스트(링크 + 한 줄 요약)를 만들어준다. 노션 MCP 접근 권한이
   있으면 직접 페이지에 추가해도 되는지 먼저 물어보고 진행한다.
3. 완성된 원고를 `archive/YYYY-Wxx.md`로 저장한다 (`Wxx`는 ISO
   주차, 예: `2026-W36.md`).

## 하지 않는 것

- 유튜브/카카오톡 API 연동, 자동 스크래핑 — 사용자가 원문을 붙여넣는 방식으로
  대체한다 (텔레그램 핵심 채널만 `scripts/telegram_digest.py`로 자동 수집).
- 네이버 블로그 자동 게시 — 최종 검토 없이 바로 올라가는 것을 막기 위해 사용자가
  직접 게시한다.
- 다른 학회원 글에 대한 주간 댓글(3개) 작성 — 이건 이 스킬의 범위 밖이다.
